Dream Builder Journal — Installable PWA package

This folder is a real PWA package, not only a single HTML file.

To become a one-tap standalone app on Android, these files must be hosted on an HTTPS web address.
After hosting:
1. Open the site in Chrome or Samsung Internet.
2. Choose Install app / Add to Home screen.
3. Dream Builder will appear with its own icon and open in a standalone window.
4. After the first load, the app can work offline and journal entries remain saved on the device.

Files:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
